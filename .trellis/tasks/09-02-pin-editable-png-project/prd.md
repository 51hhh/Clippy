# 可编辑 PNG 画布工程闭环

## Goal

让贴图画布以原图像素为唯一文档坐标，在一个标准 PNG 中同时保存可立即查看/粘贴的合成图与可继续编辑的原图、标注和调整数据，并提供安全的扁平导出、工程导入恢复和完整的兼容/校验边界。

## Requirements

### 1. 文档与坐标模型

- 原图像素坐标是画布、交互、标注、效果和导出的唯一 canonical 坐标。
- 清晰度补偿图只服务普通贴图显示，不得进入标注坐标、工程原图或导出底图。
- 打开画布时按需加载原图；不编辑且没有待渲染文档时不让每个贴图长期多驻一份解码原图。
- 工程记录原图宽高与哈希；导入时验证这些值与内嵌原图一致。
- 选择、对象移动、橡皮属于编辑操作；持久化的是 13 种标注对象及图像调整。

### 2. 可编辑 PNG 格式

- PNG 的 IDAT 是保存时的完整合成图，任何标准图片软件可直接显示。
- 一个压缩 iTXt `clippy-project` 块保存格式版本、渲染器版本、应用版本、原图 PNG、原图尺寸/哈希、annotations 与 adjustments。
- 运行时 `PinEntry` 继续用 `Arc` 共享原图；落盘工程内嵌原图字节，不保存进程内指针、临时路径或容易失效的剪贴板条目 ID。
- 工程块写入失败时不得伪装成可编辑保存成功；调用方必须区分可编辑保存与扁平保存结果。
- 工程格式对未知未来版本安全降级；旧版本必须显式迁移或拒绝恢复，不能靠当前渲染器猜测。
- 现有 v1 未记录可靠的原图坐标语义，本次升级为 v2；v1 按普通扁平 PNG 打开，不猜测迁移。

### 3. 保存、导出与剪贴板语义

- “保存可编辑 PNG”落盘 IDAT 合成图 + iTXt 工程，并把同一合成图像素写入剪贴板，支持立即粘贴。
- 已编辑图片的复制/Ctrl+C 必须复制最新合成图；不携带 iTXt 工程元数据。
- UI 明确提示可编辑 PNG 包含未打码原图，不可把它误当成安全脱敏文件。
- “导出扁平 PNG”只落盘合成图，不含工程块，适合分享模糊/马赛克后的内容。
- 剪贴板只写合成 RGBA/普通图片数据，不携带工程元数据。
- 保存后记录 document revision；未继续修改时关闭不再提示未保存。
- 文档再次修改后，复制/保存使用最新合成结果，不得回退到原图或旧预览。

### 4. 打开与继续编辑

- 主窗口提供可发现的“打开可编辑图片”入口，并支持键盘入口。
- 文件对话框选择 PNG 后：
  - 有合法工程块：用内嵌原图创建贴图，恢复 annotations/adjustments/history，显示保存时合成图并可继续编辑；
  - 无工程块、工程损坏或不支持：作为普通扁平图片打开，并允许在其上新增标注；
  - 非 PNG/过大/读取失败：给出可理解错误且不遗留窗口/PinManager 条目。
- 关闭再打开、继续编辑、再次保存后，原图与所有标注保持不变且新增操作可撤销/重做。

### 5. 信任边界与资源限制

- 读取文件前先用 metadata 检查总大小，不能先无界 `read` 再拒绝。
- 分别限制容器、合成 PNG、内嵌原图和解压后工程 JSON；应用不得生成自己拒绝读取的工程。
- base64 必须合法，原图必须是可完整解码的 PNG；尺寸、哈希必须匹配。
- annotations/adjustments 在进入 React 状态前做运行时 schema 校验，包括类型、有限数值、范围、点数量、文本长度与唯一 ID。
- 损坏工程块不能影响 IDAT 作为普通图片打开。

### 6. 渲染兼容

- 工程保存 `rendererVersion`；当前版本的工具语义必须稳定。
- 影响外观的效果参数逐步进入标注数据；本次至少固化 blur radius、mosaic cell、spotlight dim、magnifier zoom 与文本字体策略，避免只依赖未来可能变化的代码常量。
- 现有绘制顺序保持“效果在矢量前”，不在本任务内扩展为完整 PSD 混合/图层系统。

### 7. 文档与流程

- 更新架构文档，说明 canonical 坐标、IDAT/iTXt 职责、隐私语义与降级路径。
- 更新 CHANGELOG。
- 所有提交遵循 Conventional Commits；任务完成后同步 Trellis 状态。

## Acceptance Criteria

- [x] 分数缩放环境的补偿图尺寸与原图尺寸不同时，标注预览和原图导出的几何位置/尺寸一致。
- [x] 画布打开、关闭、缩放贴图后，标注不漂移，效果区域仍对应同一原图像素。
- [x] 保存的可编辑 PNG 可被普通 PNG 解码器读取，其 IDAT 像素与剪贴板合成图一致。
- [x] iTXt 明确启用压缩；真实原图 + annotations 往返后逐字段一致。
- [x] 扁平导出的 PNG 不含 `clippy-project`，可编辑保存包含它并在 UI 提示包含原图。
- [x] 应用生成的最大允许工程能够被同版本应用重新读取；超过任一上限时保存前明确失败。
- [x] 主窗口能选择普通 PNG 或可编辑 PNG 并创建贴图；取消选择不产生副作用。
- [x] 合法工程恢复原图、annotations、adjustments 与历史基线；继续画一笔后可撤销到刚打开状态。
- [x] 普通/损坏/未来版本 PNG 降级为扁平图片，不崩溃且可新增标注。
- [x] 非 PNG、伪造 base64、尺寸/哈希不符、NaN/Infinity、超长文本、重复 ID、超限点数组均被拒绝或安全降级。
- [x] 成功保存后立即关闭不提示；再次修改后关闭会提示。
- [x] `cargo build --bin clippy-app`、`./scripts/ci-local.sh --quick` 与完整 Vite build 通过。
- [x] 独立 code review 和 QA 没有未解决的 P0/P1/P2 findings。

## Out of Scope

- 完整 PSD/Krita 图层面板、混合模式、图层组与蒙版。
- 云同步、跨设备工程资产去重。
- 在系统剪贴板中传播 Clippy 私有工程 MIME。
- 非 PNG 原图格式与滚动截图。
- 修改截图覆盖层本身的取景/提交工作流；共享标注渲染器的必要兼容改动除外。
