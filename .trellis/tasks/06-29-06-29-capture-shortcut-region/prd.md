# 截图快捷键与选区体验修正

## Goal

将截图入口从主界面按钮改为可配置快捷键，并改进截图编辑体验，使选区、缩放、画布清晰度和复制导出更接近参考截图工具。

## Requirements

- 移除主界面工具栏的 Screenshot 按钮。
- 设置页新增截图快捷键绑定项，并持久化到配置。
- 截图快捷键触发截图工作流。
- 截图编辑页支持更明确的选区操作，不依赖主界面按钮入口。
- 触控板缩放不应缩放整个页面，应作用于截图画布视图。
- 画布在高 DPI/缩放场景下保持清晰。
- Copy 导出减少 UI 卡顿。

## Acceptance Criteria

- [x] 主界面不再显示 Screenshot 按钮。
- [x] 设置页可查看、录制、清空、保存截图快捷键。
- [x] 新截图快捷键可触发截图编辑窗口。
- [x] 截图画布支持选区、滚轮/触控板缩放和平移。
- [x] canvas backing store 使用 DPR，截图显示不糊。
- [x] Copy 操作导出路径减少主线程阻塞。
- [x] Rust/前端测试与构建通过。

## Out of Scope

- 不实现翻译功能。
- 不实现 OCR 截图翻译。
- 不迁移主界面到 React。
