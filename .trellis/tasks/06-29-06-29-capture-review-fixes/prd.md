# 截图融合 review 问题修复

## Goal

修复截图编辑融合后发现的运行时风险，确保截图窗口权限、失败恢复、临时贴图尺寸和多屏拼接行为可靠。

## Requirements

- 截图编辑窗口必须具备调用 Tauri IPC 和窗口 API 的 capability 权限。
- 截图捕获失败时，已隐藏的主窗口或截图窗口必须恢复显示。
- 临时截图贴图不得在前端加载后扩张到超出屏幕友好范围。
- 多显示器混合缩放场景下，截图拼接偏移应使用统一桌面坐标映射，避免空白或重叠。
- 增加覆盖关键计算和配置约束的测试。

## Acceptance Criteria

- [x] `capture` 窗口包含在 Tauri capability `windows` 中。
- [x] 截图捕获失败后可恢复先前可见窗口。
- [x] 临时贴图窗口初始渲染尺寸被限制在合理范围。
- [x] 多屏混合缩放拼接计算有单元测试覆盖。
- [x] Rust 测试、clippy、前端测试、类型检查和 Vite build 通过。

## Out of Scope

- 不新增截图编辑工具。
- 不融合翻译功能。
- 不重写现有 pin 窗口交互。
