## 功能规划

### 🔴 P0 — 高优先级（用户价值大 + 实现可行）

| # | 功能 | 说明 | 复杂度 | 里程碑 |
|---|------|------|--------|--------|
| 1 | **智能分类/标签** | 自动识别 URL / 邮件 / 代码 / JSON / 颜色值，打标签可按类型筛选 | 中 | v0.2.0 |
| 2 | **快捷粘贴** | 选中条目后直接粘贴到之前活跃的窗口（类似 CopyQ 的 Enter 粘贴） | 中 | v0.2.0 |
| 3 | **模板/片段** | 预定义常用文本片段，支持变量（日期/时间/剪贴板内容） | 中 | v0.3.0 |
| 4 | **内存优化落地** | glibc malloc 调优 + WebKit 禁用 GPU/WebGL/Audio/PageCache | 低 | ✅ v0.1.13 |
| 5 | **颜色值预览** | 检测 #hex / rgb() / hsl() 格式，在预览面板显示色块 | 低 | v0.2.0 |
| 15 | **数字键直选** | 按 1-9/0 直接选中前 10 条并粘贴，无需方向键导航 | 低 | ✅ v0.1.13 |
| 16 | **敏感内容检测** | 自动识别 API Key/Token/密码（16 种前缀+关键字），🔒标记 + 5 分钟自动清理 | 中 | ✅ v0.1.13 |
| 17 | **URL 智能预览** | 纯 URL 文本 → OG 元数据卡片（标题/描述/favicon/站名），SQLite 7 天缓存 | 中 | ✅ v0.1.13 |

### 🟢 P2 — 长线方向（差异化竞争）

| # | 功能 | 说明 | 复杂度 | 里程碑 |
|---|------|------|--------|--------|
| 11 | **LAN 剪贴板同步** | 局域网内多设备共享（mDNS 发现 + WebSocket 传输） | 高 | v0.4.0 |
| 12 | **AI 摘要/翻译** | 长文本自动摘要、翻译（本地 LLM 或 API，可选） | 高 | v0.4.0 |
| 13 | **插件系统** | Lua / WASM 脚本支持自定义处理流程 | 高 | v0.5.0 |
| 14 | **Windows / macOS 支持** | 跨平台，需解耦 Wayland/X11/gsettings 特定代码 | 高 | v0.5.0 |

## v0.2.0 发布计划

> 聚焦日常体验：智能分类 + 快捷粘贴 + 批量操作 + 颜色预览

### 核心特性
- [ ] #1 智能分类 — Rust 端添加 `content_type` 字段（url/email/code/json/color/text），前端 segment-tabs 增加分类筛选
- [ ] #2 快捷粘贴 — 记录唤起前的活跃窗口，选中后 `enigo` 模拟 Ctrl+V
- [ ] #5 颜色预览 — 正则检测颜色值，预览面板渲染色块 + 格式转换
- [ ] #8 批量操作 — Shift/Ctrl 多选模式，工具栏显示合并/导出/删除按钮

### 优化
- [ ] 前端测试覆盖率提升至 >60%（覆盖 preview-panel / app / clipboard-list 核心路径）
- [ ] Wayland Portal 快捷键迁移到 ashpd（长期替代 gsettings workaround）
