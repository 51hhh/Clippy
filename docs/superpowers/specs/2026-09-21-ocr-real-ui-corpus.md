# PX-OCR-REAL-UI-01 — 浏览器栅格化 OCR 质量语料

状态：已完成
关联路线：`PX-OCR-QUALITY-01` / `PX-ROADMAP-2026-09`

## Goal

把 OCR 质量判断从少量 Pillow 合成文字扩展到真实浏览器栅格化的 UI 场景，并保证评测入口实际核对
被评分图片的路径、PNG 身份、尺寸和 SHA-256。模型或阈值替换必须能分别观察 UI、代码、斜体、
中英日混排、表格和长图层级的改善与回退。

## Requirements

1. 新增不含个人数据的 `browser-ui-v1` 语料。源页面、文字和布局归 Clippy 仓库所有，字体继续使用
   仓库已有 OFL-1.1 Noto Sans CJK SC；截图由真实 Firefox 页面栅格化，不以 Pillow 直接绘字。
2. 语料至少覆盖浅色与暗色 UI、源码与斜体注释、中英日混排、连续空格、数字/货币/符号、表格的
   行列关系，以及高度超过普通视口的长文档。每行保存原始 Unicode、空白、四边形和阅读顺序。
3. 捕获记录保存 Firefox 版本、宿主、视口、设备像素比、源 HTML SHA、字体 SHA 和每张 PNG 的
   SHA/尺寸；已提交图片作为基线输入，不在普通测试中因浏览器升级自动重写。
4. 语料采集器与独立评测 CLI 共用同一资产校验：图片路径必须留在语料目录内，目标必须是普通且
   非符号链接的预算内 PNG，IHDR 尺寸和 SHA-256 必须与 corpus 一致。任一项不符时不能生成预测或
   报告。
5. 同一语料记录 Tesseract 与当前 PP-OCRv6 small + EdgeGNN 增强链输出；报告继续分开呈现检测、
   原始/去空白 CER、空白 F1、阅读顺序、表格和资源指标，不以总 CER 覆盖局部退化。

## Acceptance Criteria

- [x] 资产校验测试覆盖缺失文件、路径逃逸、符号链接、非 PNG、SHA 不符、尺寸不符与有效 PNG。
- [x] `browser-ui-v1` 至少包含 4 个场景，并由 schema、资产校验和生成记录共同验证。
- [x] 语料标签可以分别报告 `ui`、`code`、`italic`、`zh-en-ja`、`table`、`long-image`、`spaces` 和
  `symbols` 层级。
- [x] Tesseract 与增强链预测、报告和运行环境证据落库；文档逐层记录改善、回退和不支持能力。
- [x] OCR sidecar 单元测试与仓库本地完整门禁通过；模型权重、用户路径和私有截图不进入仓库。

## Out of Scope

- 不以本语料宣称真实世界总体精度，也不把浏览器合成页面描述成相机照片、手写或曲面文字。
- 不在本切片接入公式模型、改变产品默认模型、静默修正 Unicode 或空白，也不打包第三方模型权重。
- 不用重新栅格化后的近似图片覆盖既有基线；更新图片必须同步更新捕获记录、真值和 A/B 报告。
