# WIN-SHORTCUT-SHARED-01 — 共用快捷键的实际注册结果

## Goal

Tauri 原生注册将旧配置的相同键位去重，但每个动作必须继承该键位的实际注册结果。
不能把未注册上的共用键记为成功，或在没有任何有效键位时返回成功。
对应 WIN-NATIVE-01 / W43，基线 62d5103；这是现有按动作失败归因和部分成功合同的修复。
提取原执行协议的受控回调已复现结果记账缺口；未观察实际 Windows 系统占用或设置页行为。

## Requirements

1. 按解析后的 Shortcut ID 去重；每个唯一键位只注册一次。共享动作继承首次注册的
   成功或同一失败原因，不能清除本应保留的该动作失败状态。
2. 所有非空动作均失败时返回首个错误；独立键位部分成功继续返回 Ok，同时记录每个失败动作。
   全未配置仍返回 Ok。无效字符串仍独立报错，不能阻止其它有效键位注册。
3. 每次注册独立记账，不跨重试保留旧结果。保留 global/pin/capture 顺序、按配置的
   动作优先级、原 trim/解析规则、unregister_all 前置失败与实际事件/状态 adapter。
4. 用户保存继续拒绝按 ID 重复键；旧配置启动与恢复保持容错。保持 settings 转换锁、
   resume 的失败重试和配置持久化/副作用回滚。Linux Portal/GNOME 及默认录屏门控不变。
5. 先提取原生产计划执行协议，用受控注册/结果记录回调建立 MSVC 红基线，再以同组测试
   修复；明确提取范围。不得调用原生 register/unregister、系统输入、窗口或桌面接口。
   旧五项注册/派发测试及关联设置/配置合同保留。
6. 干净源码 SHA 完整 Windows 默认/QA 门禁，日志/源码与同 ID 文档同步。
   两个 Rust 图谱重叠不累加；真实系统冲突、桌面、其它宿主、当前 SHA CI/安装仍待验。

## Acceptance Criteria

- [x] 原去重计划与执行协议复现共用键失败被视为成功，记录实际首次失败断言。
- [x] 两个/三个动作共用键失败、同 ID 别名及独立键部分成功的失败归因正确。
- [x] 共用键成功、全空、无效配置、不同共享组与重试保持原合同。
- [x] 生产配置回滚合同与旧五项注册/优先级测试、关联文件保留。
- [x] 干净 SHA 完整 Windows 门禁、文档与分层证据同步，跳过和未验保留。

## Out of Scope

桌面操控停止；不启动应用/浏览器或实际注册系统热键，不改变共享键的动作派发优先级，
不放宽用户保存的重复键校验。不安装、推送/PR/合入/发布，不将回调替身称为 OS 冲突复现。
不把 Windows 编译或离线测试替代 Ubuntu Wayland/macOS/其它宿主和真机验收。
